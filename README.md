# midterm-report

研究生中期考核报告自动生成技能。**适用于任意研究方向**，只需 3 个文件，即可生成符合学校格式要求的中期考核报告 Word 文档。

## 它能做什么

- **自动分析研究内容**：从 PPT 和论文中动态识别研究模块结构
- **适配任意方向**：不限于特定领域，自动适应不同研究主题
- 生成 ≥6000 字、≥15 张图片的完整报告
- 三层行文逻辑（总述→概述→详述）
- 中英混合字体（宋体 + Times New Roman）
- OMML 公式支持
- 图片与图注自动交叉验证

## 你需要准备的

只需要 **3 个必需文件**，放在同一个工作目录下：

```
你的工作目录/
├── 研究生成绩单.pdf    ← 必需（课程成绩、学分、绩点）
├── 论文.pdf           ← 必需（技术内容来源）
└── 中期ppt.pdf        ← 必需（工作框架来源）
```

**可选文件：**
- `图片/` 目录 — 如果你已有准备好的图片，可以放在这里。没有的话，技能会自动从论文和 PPT 中提取。

**不需要的文件：**
- ~~模板.docx~~ — 格式规范已内置在技能中
- ~~中期考核相关资料.docx~~ — 考核要求已内置
- ~~参考文档~~ — 图片验证通过视觉模型完成

## 适用领域

本技能适用于**任意研究方向**，包括但不限于：

| 类型 | 示例领域 |
|------|---------|
| 工程实现型 | 控制工程、信号处理、嵌入式系统、机器人、通信工程 |
| 理论推导型 | 控制理论、算法设计、机器学习、优化理论、数学建模 |
| 混合型 | 计算机视觉、自然语言处理、深度学习、模式识别 |

## 使用方法

### 第一步：准备材料

将 3 个必需文件放到同一个目录下，例如：

```
D:\我的中期汇报\
├── 研究生成绩单.pdf
├── 论文.pdf
└── 中期ppt.pdf
```

### 第二步：调用技能

在 Claude Code 中输入：

```
/midterm-report
```

或者直接描述需求：

```
请帮我生成中期考核报告，工作目录在 D:\我的中期汇报\
```

### 第三步：交互确认

技能会询问你：

1. **确认模块结构**：技能会自动分析 PPT，识别研究模块。向你确认检测到的模块是否正确。
2. **选择模板类型**：
   - **lyw-模板**（工程实现型）— 适合工程类、实验验证为主、图片多（≥15 张）
   - **yl-模板**（理论推导型）— 适合学术类、理论推导为主、公式多（≥25 个）

### 第四步：等待生成

技能会自动完成：
1. 从 PPT 和论文中提取图片
2. 交叉验证每张图片的真实含义
3. 规划报告结构（根据检测到的模块动态生成）
4. 生成 python-docx 脚本
5. 执行脚本生成 Word 文档
6. 验证字数、图片数量、格式
7. 用视觉模型核验图注匹配

### 第五步：获取结果

生成完成后，你的工作目录下会多出：

```
你的工作目录/
├── 研究生成绩单.pdf
├── 论文.pdf
├── 中期ppt.pdf
├── 写入文件.docx          ← 最终报告文档
├── rewrite_report.py      ← 生成脚本（可复用/修改）
├── ppt_images/            ← 从 PPT 提取的图片
└── paper_images/          ← 从论文提取的图片
```

## 模板选择指南

| 特征 | lyw-模板（工程型） | yl-模板（理论型） |
|------|-------------------|-------------------|
| 适合专业 | 工程类专业学位 | 学术学位 |
| 研究特点 | 系统开发、实验验证 | 算法创新、理论推导 |
| 公式数量 | 较少（<20 个） | 较多（≥25 个） |
| 图片数量 | 较多（≥15 张） | 适中（~20 张） |
| 思想品德 | 详细（~600 字，列课程） | 简洁（~200 字） |
| 科研工作 | 三层逻辑，（1）（2）编号 | 直接展开，1. 2. 编号 |
| 下一步计划 | 日期范围 + 详细描述 | 编号列表 + 简短目标 |

**快速判断：** 如果你的研究核心是"做了一个系统/平台"→ lyw-模板；如果是"提出了一个算法/方法"→ yl-模板。

## 报告结构

| 章节 | 内容 | 篇幅 |
|------|------|------|
| 一、思想品德与业务学习情况自述 | 政治思想、课程成绩、学习态度 | ~20% |
| 二、已完成的科研工作 | 总述→概述→详述 + 技术模块 | ~60% |
| 三、下一步科研计划 | 分阶段科研安排 | ~20% |

## 图片验证

生成报告前，可先验证图片是否满足要求：

```bash
E:/Anaconda/python.exe verify_images.py D:\你的工作目录
```

检查内容：
- 图片数量 >= 15
- 图片格式有效（PNG/JPG/TIFF/BMP）
- 图片宽度 >= 400px
- 图片编号连续无跳号
- 文件大小 >= 5KB（排除损坏文件）

## 常见问题

**Q: Python 执行报错 exit code 49？**
A: Windows 下使用完整路径 `E:/Anaconda/python.exe <file>`

**Q: 字数不足 6000？**
A: 在数据预处理、实验验证、方法描述等位置补充技术细节

**Q: 图片不够 15 张？**
A: 技能会自动从论文和 PPT 中提取，也可以在 `图片/` 目录中手动添加

**Q: 图注与图片不匹配？**
A: 技能会自动进行交叉验证，如有问题会提示确认

**Q: PPT 模块检测不准确？**
A: 技能会先向你确认模块结构，你可以手动调整模块划分

**Q: conda run 报错？**
A: 不要使用 `conda run -n base python -c "多行代码"`，始终将代码写入文件后执行
