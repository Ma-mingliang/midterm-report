# 中期考核报告自动生成技能 (midterm-report)

基于 Claude Code 的研究生中期考核报告自动化生成技能。通过 python-docx 自动生成符合学校格式要求的 Word 文档。

## 功能特性

- **自动化文档生成**：基于模板自动填充三个章节内容
- **三层行文逻辑**：总述→概述→详述，与模板写作逻辑完全一致
- **中英混合字体**：中文宋体 + 英文 Times New Roman，符合学术规范
- **OMML公式支持**：Word原生公式格式，带自动编号
- **图片来源验证**：从参考文档提取图片，逐图比对文件大小确认一致性
- **图注二次核验**：通过视觉模型验证每张图片与图注的对应关系
- **格式严格对标**：字体、编号、排版与模板完全一致

## 使用方法

### 1. 准备材料

在工作目录下放置以下文件：

```
工作目录/
├── 模板.docx              # 格式模板
├── 中期考核相关资料.docx   # 考核要求
├── 研究生成绩单.pdf        # 成绩数据
├── 论文.pdf               # 技术内容来源
├── 中期ppt.pdf            # 工作框架来源
├── 写入文件(3).docx       # 参考文档（用于图片验证）
├── 图片/                   # 原始图片
├── paper_images/           # 论文提取图片（可选）
├── ppt_images/             # PPT提取图片（可选）
└── ref_figures/            # 参考文档提取图片（最可靠）
```

### 2. 调用技能

在 Claude Code 中输入：

```
/midterm-report
```

或直接描述需求：

```
请帮我生成中期考核报告，工作目录在 D:\我的中期汇报\
```

### 3. 交互流程

技能会自动：
1. 扫描材料并确认信息来源
2. 从PPT/论文/参考文档提取图片
3. 验证图片来源的正确性
4. 规划报告结构和三层行文逻辑
5. 生成 python-docx 脚本
6. 执行脚本生成 Word 文档
7. 验证字数、图片数量、格式
8. 用视觉模型核验图注匹配

## 输出

- `写入文件.docx` — 最终报告文档
- `rewrite_report.py` — 生成脚本（可复用/修改）
- `ref_figures/` — 从参考文档提取的图片

## 报告结构

| 章节 | 内容 | 篇幅 |
|------|------|------|
| 一、思想品德与业务学习情况自述 | 政治思想、课程成绩、学习态度 | ~20% |
| 二、已完成的科研工作 | 总述→概述→详述 + 6个技术模块 | ~60% |
| 三、下一步科研计划 | 分阶段科研安排 | ~20% |

### 第二章三层行文逻辑

```
开篇总述（研究目的 + 整体框架 + 框架图）
  ↓
六部分简要概述（每个模块1-2句话）
  ↓
"已完成工作：" 过渡标记
  ↓
详细展开（6个模块 × 方法/图片/验证/创新点）
```

## 格式规范

- 正文：宋体/Times New Roman 12pt
- 图注：宋体/Times New Roman 10pt，居中，样式a3
- 图片编号：图1 图2...连续无跳号
- 小节编号：（1）（2）（3）...
- 行距：1.5倍（line=360），段后间距0

## 自定义

### 修改章节结构

编辑 `rewrite_report.py` 中的 `write_section1/2/3` 函数。

### 修改字体

修改 `set_run_font` 函数中的字体设置：

```python
rFonts.set(qn('w:eastAsia'), '黑体')  # 中文字体
rFonts.set(qn('w:ascii'), 'Arial')     # 英文字体
```

### 修改图片宽度

修改 `add_img` 调用中的 `width` 参数：

```python
add_img(cell, rimg('ref_fig1.png'), width=Inches(4.0))  # 缩小图片
```

### 添加新公式

在 `omml_formulas.py` 的 `FORMULA_BUILDERS` 字典中添加构建函数。

## 常见问题

**Q: Python执行报错 exit code 49？**
A: Windows下使用完整路径 `E:/Anaconda/python.exe <file>`

**Q: 字数不足？**
A: 在数据预处理、实验验证、控制律分析等位置补充技术细节

**Q: 图注不匹配？**
A: 必须用视觉模型逐张核验，不能仅凭文件名判断

**Q: PPT图片命名与实际页码不一致？**
A: 不要信任任何图片文件名。从参考文档（写入文件(3).docx）中提取图片是最可靠的方法。

**Q: conda run 报错？**
A: 不要使用 `conda run -n base python -c "多行代码"`，始终将代码写入文件后执行。
